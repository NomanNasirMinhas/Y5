# Generation prompts

## Graphite amber

Use case: ui-mockup. Create a high fidelity desktop UI prototype for Y5 Airwave Audit Console, a retro Wi-Fi security testing desktop application. Concept A: graphite charcoal panels, warm off-white readable text, restrained amber accents, green only tiny success dots. No green wash, no neon glow. Flat straight-on full app screenshot, 1440x1000 composition. Compact left navigation Scan, Targets, Captures, Interfaces, Log. Main Network discovery page: startup check strip 'Tools ready / wlan0 · monitor / Recovery enabled', interface and channel toolbar, obvious Stop scan button in muted red, statistics, network table with checkboxes for single or multi selection and columns Network BSSID Channel Signal Security. Fictitious Lab-router and Test-network rows, bottom selection bar '2 selected' and 'Review targets'. Right narrow activity pane. Retro typography and thin rules inspired by vintage lab instrumentation, modern legibility and generous spacing. Include small mobile layout inset bottom right showing stacked cards. This is a design exploration, not an existing app screenshot.

## Slate cyan

Use case: ui-mockup. Design Concept B for Y5 Airwave Audit Console desktop Wi-Fi testing tool. Straight-on polished high fidelity full app screenshot, wide landscape. Retro workstation style with slate navy backgrounds, off-white readable text, restrained muted cyan blue active controls, warm orange warnings, no dominant green and no glow. Top tab navigation Scan / Targets / Captures / Interfaces / Log. Compact Network discovery title, startup tools checklist card with 'All core tools installed', 'wlan0 · monitor', 'Restore on exit'. Main table with radio/checkbox selection, fictitious Lab-router and Test-network entries, BSSID/channel/signal/encryption columns, 2 selected, Review targets button. Obvious red Stop scan button and scan duration. Bottom activity console narrow and organized. Strong typography hierarchy, thin borders, subtly rounded instrument panels and generous spacing. A small mobile inset at lower right shows responsive stacked network cards and prominent Stop scan. An alternative design exploration, visually distinct from amber charcoal: blue slate, horizontal navigation and wider central workspace. No green wash, no decorative hacker imagery.
